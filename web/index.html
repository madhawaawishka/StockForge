Interactive Guided Demo Sequence Recommended Path

Follow this 8-step sequence to demonstrate the platform's distributed systems capabilities to any interviewer.

1

Create Flash-Sale Product (Admin)

POST /api/v1/admin/products

Creates a catalog product with time-ordered UUIDv7 and stock conservation check (available + reserved + sold = total).

2

Check Availability & ETag Caching (Alice)

GET /products/{id}/availability

Fetches product availability from Redis cache with single-flight stampede protection. Re-requesting with If-None-Match returns 304 Not Modified.

3

Reserve Stock Atomically (Alice)

POST /reservations

Executes a single conditional UPDATE ... WHERE available_quantity >= qty. Guaranteed zero overselling. Requires mandatory Idempotency-Key.

4

Verify At-Most-Once Idempotent Replay

Idempotent-Replayed: true

Re-submits the exact same reservation with the identical Idempotency-Key. Returns the original response with header Idempotent-Replayed: true without reserving another unit!

5

Happy Path Saga Checkout (Async Accepted ➔ Confirmed)

POST /orders (202 Accepted)

Orders created asynchronously (202 Accepted + Location). Order service saga orchestrator dispatches payment over Kafka. Transitions: PENDING_PAYMENT ➔ CONFIRMED.

6

Saga Failure & Automatic Rollback Compensation

X-Payment-Simulation: FAILED

Injects a simulated payment failure. The saga triggers a compensating transaction: order becomes CANCELLED, stock returns to AVAILABLE, and the cancellation notification is delivered.

7

Broken Object-Level Authorization Defense (BOLA)

Bob reads Alice's order ➔ 404

Switches caller to Bob and attempts to query Alice's order. Returns 404 Not Found instead of 403, preventing attackers from probing whether the Order ID exists (OWASP API Top 10 #1).

8

High-Concurrency Flash-Sale Burst (Contention Test)

15 Simultaneous Buyers

Launches 15 simultaneous parallel reservation requests competing for remaining stock. Proves that database row-locking eliminates lost updates: exactly available stock is reserved, losers get clean 409 Conflict, and Zero units are oversold.
